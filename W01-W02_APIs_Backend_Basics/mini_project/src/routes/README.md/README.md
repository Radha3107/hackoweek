# TaskFlow API

A simple RESTful Task Management API built using Node.js and Express.js as part of HackoWeek W01-W02: APIs & Backend Basics.

## Features

- Create a task
- View all tasks
- View a task by ID
- Update a task
- Delete a task
- Basic request validation
- Proper HTTP status codes
- RESTful API routing

## Tech Stack

- Node.js
- Express.js
- JavaScript
- Thunder Client for API testing
